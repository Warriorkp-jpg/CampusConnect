Connecting to Your Live Django Backend (`127.0.0.1:8000`)

When switching the top toggle from Demo Sandbox to Live Django API, browsers require django-cors-headers so your frontend HTML file is allowed to call http://127.0.0.1:8000.

1. Install CORS Headers in your Terminal:
pip install django-cors-headers
2. Add to rbac_project/settings.py:
INSTALLED_APPS = [
    ...
    'corsheaders',  # Add this
    'rest_framework',
    'accounts',
    'drive',
    'application',
]

MIDDLEWARE = [
    'corsheaders.middleware.CorsMiddleware',  # Add at the VERY TOP!
    'django.middleware.security.SecurityMiddleware',
    ...
]

CORS_ALLOW_ALL_ORIGINS = True  # Allow frontend to talk to Django API
